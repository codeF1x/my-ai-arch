# Project Rules

## 1. Project Structure

- This is a Next.js project using App Router.
- UI components are in `components/`.
- Database schema is in `db/`.
- Utilities are in `lib/`.

## 2. Tech Stack

- Framework: Next.js 15+ (App Router)
- Language: TypeScript
- Styling: Tailwind CSS
- Database: Postgres (via Drizzle ORM)
- AI: Vercel AI SDK

## 3. Development Guidelines

- Use `npm run dev` to start the development server.
- Ensure all new components are typed correctly.
- Use `drizzle-kit` for database migrations.

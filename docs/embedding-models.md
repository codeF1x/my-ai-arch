# Embedding 模型对比 (2026)

云端向量嵌入模型（Embedding）的收费通常按照 **Tokens（字符或词元单元）** 计费。2026 年，由于技术成熟和市场竞争，各大厂商的单价普遍有所下降。

## 3. 成本计算示例

假设您有一本 **10 万字** 的电子书需要存入向量数据库：

1.  **分词估算：** 10 万汉字约为 15 万 Tokens（含标点和格式）。
2.  **OpenAI (small):** 约花费 $0.003（约人民币 **0.02 元**）。
3.  **阿里云/智谱:** 约花费 **0.075 元**。

> **注意：** 相比大语言模型（如 GPT-4o 动辄数美元），向量模型的成本非常低，通常在整个 AI 系统支出中占比不到 5%。

## 4. 当前项目配置

本项目目前支持以下 Provider:

1.  **DeepSeek**: 使用 `deepseek-v3-embed` (默认)
2.  **OpenAI**: 使用 `text-embedding-3-small`
3.  **Google**: 使用 `text-multilingual-embedding-002`

### 💡 建议

- **初期测试：** 建议先在 **智谱 AI** 或 **OpenAI** 开通，它们通常会给新用户赠送 **500 万 - 1000 万** 的免费 Tokens。
- **大规模落地：** 如果您的数据量达到亿级 Token，建议关注 **阿里云的 Batch（批处理）接口**，可以节省 50% 的费用。
